───────────────────────────────  0:00
[ say your name / class / school first ]
[ PRESS "drop it" ]
[ SILENCE. 3 seconds. Let it land. ]

That's a box of food dropped
out of a helicopter, /
and nothing's steering it.

It landed twenty-four metres off.


───────────────────────────────  0:10
[ stay put · don't scroll ]

In the Assam floods last July, /
eighty thousand people could only
be reached by air.

So I built a mathematical model
of a parachute that steers itself
to a target.


───────────────────────────────  0:24
        ** WHAT I ACTUALLY BUILT **
[ SCROLL to 02 · IT ISN'T A NORMAL PARACHUTE ]

It's a parafoil — a wing, not a dome. /
It glides forward as it falls,
and pulling one side turns it.

From its weight and its canopy size /
I worked out how fast it flies
and how tightly it can turn.

It sinks at a steady rate. /
So the moment it's dropped I know
how long it has in the air —
and how far it can fly.

I wrote the steering to spend
exactly that. /
That's why it weaves instead of
arriving early.


───────────────────────────────  0:58
        ** WORKING OUT THE WIND **
[ SCROLL to 03 · NO WIND SENSOR ON BOARD ]
[ CLICK "force it straight" ]

It carries no wind sensor. /
I wrote a filter that works
the wind out for itself.

GPS knows how fast it's crossing
the ground. /
My model knows how fast it moves
through the air.
The wind is what's left.

But flying straight, you can't tell
a headwind from simply flying slower. /
Forced straight — it's three metres
a second wrong.

[ CLICK "let it turn" ]

Turning tells them apart.

Four centimetres.


───────────────────────────────  1:26
[ SCROLL BACK UP to the first drop ]

And it was already turning — /
that's the weaving.

So working out the wind
cost nothing extra.


───────────────────────────────  1:36
          ** WHAT I FOUND **
[ SCROLL to 06 · THE FINDING ]

Then I tested every combination — /
three thousand drops, every weight
against every wind.

A heavier one flies faster,
so it handles more wind. /
But it turns wider, so it corrects
less well at the end.

Double the wind you build for /
and you need four times the weight —
and that turns four times wider.

So every wind has a best weight. /
And it's only ballast — you set it
on the day.

───────────────────────────────  2:00
                                  END

 WHAT THE JUDGE SHOULD BE ABLE TO REPEAT
   1. She built a mathematical model of a
      self-steering relief parafoil.
   2. It glides, so it can be steered — and it
      has a fixed amount of flying in it, which
      is why it weaves.
   3. It finds the wind with no wind sensor,
      from GPS plus the flight model — and only
      turning makes that possible, which it was
      doing anyway.
   4. Heavier handles more wind but turns wider,
      so every wind has a best weight — and the
      weight is just ballast.

 IF ASKED: isn't the one that's TOLD the wind better?
   On the median, a bit — but the error bars overlap,
   so at 150 drops those two aren't actually separated.
   What I can back up: drop for drop it cuts the miss
   by 4.26 metres, and it wins 112 times out of 150.

 IF ASKED: has nobody done this?
   They have. Naval Postgraduate School lands one within
   3 metres. ParaDrone flies these paths on a hobby
   microcontroller. What neither of them publishes is how
   the weight and the wind together decide the accuracy.
   That part is mine.

 IF ASKED: is this simulated or real?
   Simulated — a mathematical model, and I say so in the
   video. No turbulence, no canopy flexing, no servo lag.
   The model names a test build — 1 m2 canopy, 0.5 to
   0.8 kg — so a real flight can check it.
